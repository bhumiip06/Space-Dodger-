# 🚀 Space Dodger

A simple 2D arcade game built with **Python** and **Pygame** where the player must dodge falling enemies, survive as long as possible, and achieve the highest score.

---

## 🎮 Gameplay

Control the player using the arrow keys while avoiding randomly spawning enemies. The game becomes more challenging as your score increases. Beat your previous high score and keep improving!

---

## ✨ Features

- 👾 Multiple falling enemies
- 🎯 Collision detection
- 📈 Dynamic difficulty increase
- 🏆 High score saved locally
- 🔊 Background music
- 💥 Collision sound effects
- 🔄 Restart button
- ❌ Game Over screen
- 🎲 Random enemy spawning

---

## 🕹️ Controls

| Key | Action |
|------|--------|
| ⬅️ Left Arrow | Move Left |
| ➡️ Right Arrow | Move Right |
| ⬆️ Up Arrow | Move Up |
| ⬇️ Down Arrow | Move Down |

---

## 📦 Installation

### Clone the repository

```bash
git clone https://github.com/bhumiip06/Space-Dodger-.git
```

### Navigate to the project folder

```bash
cd Space-Dodger-
```

### Install Pygame

```bash
pip install pygame
```

### Run the game

```bash
python main.py
```
