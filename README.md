# 🎮 Dodge the Enemies

A simple 2D arcade game built using **Python** and **Pygame**.

The objective is simple:
Avoid all falling enemies and survive as long as possible to achieve the highest score.

---

## Features

- Multiple falling enemies
- Collision detection
- Increasing difficulty
- Background music
- Collision sound effect
- High Score saving
- Restart button
- Game Over screen
- Random enemy spawning

---

## Controls

⬅ Left Arrow – Move Left

➡ Right Arrow – Move Right

⬆ Up Arrow – Move Up

⬇ Down Arrow – Move Down
